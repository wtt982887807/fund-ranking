# 银河与国泰海通基金排名

网页支持逐份导入银河/国泰海通报表、修改默认51只产品、原格式Excel与动态热力图导出，以及特殊手排和并列名次单元格备注。报表仅在访问者浏览器内读取计算。

## 发布

将本目录的文件放在GitHub仓库根目录，在 Settings → Pages 选择 Deploy from a branch、main、/(root)，保存并等待GitHub生成访问链接。index.html应位于仓库根目录。

## 使用

打开网页链接后选择报表；无需等待五份文件齐全。可修改产品清单或导入/导出JSON清单。开始新月份前先清空本次报表。

修改的产品清单保存在当前浏览器，原Excel报表不存储到服务器。

SheetJS与JSZip许可文件随代码提供。
